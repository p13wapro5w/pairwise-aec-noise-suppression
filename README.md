# pairwise-aec-noise-suppression

开黑时队友听到自己的回声，回声消除的参考信号比麦克风晚了两百毫秒，线性自适应滤波器把语音也当成回声削掉；声卡时钟漂移，参考与采集每十分钟差出几十毫秒，滤波器逐渐发散；双讲时滤波器系数冻结不及时，一方说话另一方被压成断续；非线性扬声器失真没建模，大音量下残留回声；采样率 48k 与 44.1k 混用，参考信号重采样后相位不一致；缓冲欠载插入静音，自适应滤波器把静音段当成双讲；噪声抑制与回声消除串行执行，降噪后的信号让回声路径估计失准；增益控制放在 AEC 之前，音量变化让滤波器重新收敛；房间声学变化后没重置，换房间后回声残留；播放端音量拉到最大，削波后的参考信号无法线性建模。media/aec_noise_suppression.py 是核心，tests/test_aec_noise_suppression.py 15个红。要修的是：参考延迟对齐；时钟漂移补偿；双讲检测；非线性残差抑制；统一采样率；欠载保护；AEC 先于降噪；增益在 AEC 之后；场景变化重置；参考信号限幅。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
